# Contributing

Read [methods](docs/METHODS.md), [data access](docs/DATA.md) and [status](docs/STATUS.md). Browser and research code have different execution contracts.

## Issues

Include the commit, source path, operating system, dependency versions, command, expected behavior and actual output. Prefer minimal synthetic inputs. Do not attach private measurements, credentials, unlicensed geometry or restricted replay packages.

For numerical discrepancies, identify the output, input shape/dtype, baseline and comparison rule. Do not round away a mismatch or invent a tolerance after observing it.

## Changes

Keep preprocessing, precision, role assignments and fallback behavior explicit. Separate performance changes from algorithm changes; test complete outputs before claiming equivalence. Add targeted synthetic tests, including invalid inputs and failure paths.

Preserve original evidence and disclose behavior changes. Report adverse cases and all prescribed comparisons for scientific changes. Do not remove integrity checks or broaden access merely to make an archived runner execute.

State code/asset origins and applicable terms. Describe substantive AI assistance when relevant to provenance; do not invent human approval, contributor identities or upstream endorsement. Code review is not aerodynamic safety certification.
