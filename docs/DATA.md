# Data and access

## Release scope

The new archive contains source and technical documentation, not the current manuscript, its figures or private reproduction packages. Existing site assets and older study material retain their own histories; retaining them does not relicense them or merge their population with newer experiments.

Three older paper records are removed from the current public tree: `study/NeuralFoil-Study-Complete-Record.pdf`, `study/data/research-answer.md`, and `study/docs/paper-outline-FINAL.md`. Working copies are preserved locally and already-public Git history is not erased. Historical mentions of those names do not provide a current-tree download. No ordinary measurement data or source code is removed by this paper-only exclusion.

Research scripts may reference absent local files. A path is not a download link, and a checksum cannot reconstruct an unavailable input.

## Permissions and required inputs

The legacy `study/README.md` declares `data/*.csv` CC-BY 4.0, `tools/` MIT, and documents all rights reserved pending submission. That is a historical repository declaration, not newly verified clearance for every underlying source or a license for the new research tree. In particular, it must not be used to relicense recovered coordinates or broader measurement archives.

Published performance-data terms, software licenses and recovered coordinate/archive rights are different permissions. Public availability alone does not settle onward redistribution.

This source release supplies no blanket right to redistribute measurements, recovered coordinates, fitted artifacts or label-bearing replay arrays. It does not promise those materials will be shared on request.

For reconstruction, identify the procedure's geometry, conditions, targets, memberships and model artifacts, preserving order and precision. Use synthetic examples for public bug reports when the real input cannot be shared.

A nominal geometry does not verify every as-built surface or hinge. A transition sensitivity is not measured turbulence. Complete and eligible panels have different denominators. Saved predictions are not independent experiments, and this repository is not a complete research-workspace backup.
