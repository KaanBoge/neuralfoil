What “error reduction” means

Mean absolute error (MAE) averages the absolute difference between predicted and measured drag. Reduction is 100 × (MAEbaseline − MAEmethod) / MAEbaseline. An average gain does not mean that every prediction improves.

These percentages do not establish improvements in lift, moment, stall, flight safety or optimization derivatives.

The gain–harm trade-off

A half-strength core correction gives smaller historical gains but positive mean reductions across all 31 reported views against both native baselines. Those views overlap, and individual observations and identities still worsen.

Stronger calibration and numerical-bound experiments did not satisfy all unchanged advancement criteria. Their inclusion in the archive does not mean they passed.

A shared correction, not one fix per airfoil

How the research changes a prediction.

Airfoil names are not deployment features. The model responds to numerical geometry and conditions; that enables transfer in principle, but does not guarantee good transfer to an unseen case.

  1. 01

    Start with native models

    Run the eight NeuralFoil sizes and form the mean-of-eight drag baseline. The pretrained network weights stay unchanged.

  2. 02

    Describe the query

    Construct X62: 24 baseline/operating descriptors, 20 transition-sensitivity descriptors and 18 Kulfan geometry coefficients.

  3. 03

    Learn a bounded adjustment

    The core learns a clipped relative drag residual. A separate strength policy chooses how much of that correction to apply.

  4. 04

    Apply the declared gate

    The point-correction procedures return the mean-of-eight baseline outside their gate. Falling back avoids applying that correction; it does not prove the baseline is accurate.

Feature contract and inherited operating gate

The inherited gate requires finite inputs, positive baseline drag, 0 < Re ≤ 600,000, |α| ≤ 12° and 0.05 ≤ thickness/chord ≤ 0.20. Nominal research inference uses Mach zero and free transition. Qualified procedures may add separately declared numerical guards.

The feature order, original coordinate-to-Kulfan convention and rounding are part of the contract. The 20 sensitivity features use alternative ncrit = 5, 7, 11, 13 against 9; they are model sensitivities, not measured tunnel turbulence. Passing a shape check does not prove compatibility.

The portable entry point consumes already constructed features, baseline predictions, an artifact and a Boolean gate. It does not turn arbitrary coordinates into a certified answer. See the complete public method guide.

Why numerical bounds are not another accuracy percentage

Interval projection, added-loss calibration and tree enclosures answer different questions. A tighter enclosure bounds a specified numerical evaluator; it does not imply the same percentage improvement against measured drag, or that every enclosed extremum is attainable.

The later eight-tree work is a separate numerical-bound experiment, not a new eight-tree accuracy result. Hard gates and trees also do not preserve global differentiability.

    What the public release does—and does not—contain

    Source publication is not a complete private-workspace backup or a ready-to-use trained correction package. The current paper and its figures, new trained artifacts, recovered measurements and geometry, private replay packages, environments and dependency caches are excluded. Public historical assets retain their separate provenance.

    Code can name a missing file without supplying it. Some archived scripts retain home-directory placeholders and local assumptions. The synthetic public example checks an interface, not aerodynamic accuracy. For publication completeness and explicit exclusions, consult the source guide.

    Original code and new associated technical documentation use the MIT License. Third-party code, network assets and research data retain their applicable terms. MIT permission is not safety certification.

    What stronger evidence requires

    The next milestone is independent validation.

    Untouched experimental measurements, a frozen model and evaluation protocol, a reproducible deployment contract, and explicit reporting of both gains and harms. More parameter searching on reused outcomes cannot substitute for that evidence.
